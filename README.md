# Fridge Roast: One Line, Biggest Laugh

Entry for the [Fridge Roast: One Line, Biggest Laugh](https://make.fun/c/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) bounty on [make.fun](https://make.fun).

## The entry

> Its touchscreen freezes more often than the ice cream, and the only fix is unplugging the whole fridge like it's 1998.

The one thing in the fridge that actually freezes is the touchscreen — and the official fix is unplugging the whole appliance, like tech support from 1998. It roasts the smart fridge's door screen (not a generic gadget), lands its punchline in two beats (the inversion, then the 1998 kicker), and steers clear of the obvious cracks: no grocery-ordering, no spying camera, no bricked ice maker, no paywalled ice.

## How it works

`main.py` (Python 3.13, standard library only, deterministic — no network, no clock, no randomness) writes the single entry line (118 characters) to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
